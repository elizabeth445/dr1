# Після шостої / AFTER HOURS

Экспериментальный сайт-приглашение на день рождения Софии: 28 ноября 2026, 18:00, Киев. Интерфейс — украинский. Новый дизайн реализован в существующем проекте с сохранением логики и формата локальных ответов.

## Запуск

Требуется Node ≥22.12. Если runtime не найден:

```sh
source ~/.codex/bin/frontend-env.sh
npm ci
npm run dev
```

Открыть **http://127.0.0.1:5180/**. Сервер привязан к этому компьютеру. Можно также запустить `start.command` после установки зависимостей.

```sh
npm run build
npm run preview -- --port 5198 --strictPort
```

Production preview: http://127.0.0.1:5198/. Готовая статическая сборка — `dist/`. Внешние API, ключи и backend не нужны. Исходники: [elizabeth445/dr1](https://github.com/elizabeth445/dr1), ветка `main`. Развёртывание сайта выполняется отдельно.

## Замечания через Agentation

При `npm run dev` справа внизу доступна панель Agentation: активируйте её, нажмите на элемент, напишите замечание и нажмите Add. Кнопка Copy копирует замечания с привязкой к элементам — вставьте их в чат для внесения правок. Панель доступна также поверх вступительного билета и открытого фото. Agentation рассчитан на desktop; в production-сборку он не включается. Если localStorage запрещён, панель отключается, чтобы её ошибка не мешала работе сайта. MCP-синхронизация и отправка на внешние сервисы не подключены.

## Где менять событие

Все основные данные находятся в **`src/config/eventConfig.ts`**:

| Поле                                        | Что меняет                                                |
| ------------------------------------------- | --------------------------------------------------------- |
| `name`, `initial`, `title`                  | Имя, знак на билете, название события                     |
| `age`                                       | Возраст; `null` скрывает его                              |
| `startsAt`, `endsAt`, `timeZone`            | Точная дата/время, таймер и календарь                     |
| `city`, `venue`, `address`                  | Город, заведение, адрес                                   |
| `addressVerified`                           | Показывать маршрут только после проверки реального адреса |
| `meetingNote`                               | Сообщение о встрече                                       |
| `dressCode`, `dressCodeNote`, `dressColors` | Дресс-код и акценты                                       |
| `schedule`                                  | Время и описание пунктов программы                        |
| `invitation`                                | Личное приглашение                                        |
| `heroPhoto`, `photos`                       | Изображения, описания и подписи                           |
| `rsvpDeadline`, `allowGuests`, `maxGuests`  | Срок ответа и общее число гостей, включая отвечающего     |
| `theme`                                     | Чёрный, лайм, коралл и мел                                |

`startsAt` и `endsAt` — ISO со смещением. Для Киева 28.11.2026 используется `+02:00`; при смене даты учитывайте сезонное смещение. `Europe/Kyiv` применяется для отображения независимо от часового пояса гостя. Демоадрес отсутствует: показывается «Локацію повідомимо окремо».

Фотографии положите в `public/images/`, затем укажите пути в конфиге. Замените описания, чтобы они соответствовали новым кадрам. Структура афиши и название «Після шостої» — `src/App.tsx`, `src/components/Opening.tsx` и `src/sections/`. Цвета и шрифты — `src/styles/tokens.css`, композиции — `src/styles/global.css`.

## RSVP и календарь

Форма проверяет имя и выбор присутствия, сохраняет ответ, позволяет изменить или удалить его. Ключ `invitation:rsvp:v1:sofia-birthday-2026` сохранён при редизайне. Менять `id` события нужно осознанно: он определяет отдельное хранилище ответов.

**Ответ остаётся только в localStorage текущего браузера и не передаётся Софии.** Удаление данных браузера удалит ответ. Ошибка доступа к хранилищу отображается; данные остаются в форме. Для настоящего сбора ответов потребуется backend или согласованная внешняя форма.

Календарь скачивается в `.ics`: UTC-время, UTF-8, CRLF и переносы строк по RFC 5545. После начала события таймер показывает нули и сообщение о начале вечера.

## Дизайн, изображения и движение

Арт-дирекция и исследованные ориентиры — **`design.md`**. Unbounded Black + IBM Plex Sans + IBM Plex Mono. IBM Plex Sans Condensed не использован: проверенные файлы не содержат кириллицы. Полный украинский алфавит проверяется по cmap исходных TTF; браузер использует локальные компактные WOFF2, только Cyrillic и Latin.

Билет — SVG-высечка, DOM-печать, бумажная фактура, торец, подложка, отдельные перфорация и корешок. GSAP режиссирует отрыв и раскрытие строк афиши. Motion обслуживает состояния RSVP. Lenis работает только на desktop с точным указателем через единственный GSAP ticker; на touch — нативная прокрутка. Reduced motion отключает пространственные анимации, параллакс и колебание пламени. Skip, Escape и повтор открытия доступны.

Оригинальные AI-ассеты и точные промпты: **`assets/image-prompts.md`**. Они не являются фотографиями именинницы или реального события. Дополнительный кадр коктейля — [Unsplash](https://images.unsplash.com/photo-1470337458703-46ad1756a187), [лицензия](https://unsplash.com/license). Шрифты — SIL OFL; действующие лицензии в `public/fonts/`.

## Проверки

```sh
npm run lint
npm run typecheck
python3 scripts/check-fonts.py
npm run build
npm test
```

Playwright использует отдельный профиль Chromium/Chrome, не личный профиль. Проверяет вступление, клавиатуру и возврат фокуса, галерею, touch-свайп, свечу, валидацию/сохранение/редактирование RSVP, отказ localStorage, календарь, конец таймера, отсутствие сломанных изображений, ошибок JavaScript и внешних запросов, axe и reduced motion.

Адаптивные снимки и проверки: 320, 375, 390, 430, 768, 1024, 1440, 1920 px, короткий landscape и смена ширины после анимации. Скриншоты генерируются в `output/qa/`, HTML-отчёт — в `playwright-report/`; эти воспроизводимые файлы исключены из Git. При необходимости собрать сравнительные листы: `python3 scripts/qa-contact-sheets.py` (нужен Pillow).

Чтобы запускать тесты против production preview: `PLAYWRIGHT_BASE_URL=http://127.0.0.1:5198 npm test`. Физические устройства и Safari/Firefox этим прогоном не проверяются.

## Подготовка к GitHub и Vercel

Vercel: preset **Vite**, Install Command **`npm ci`**, Build Command **`npm run build`**, Output Directory **`dist`**. Для этой статической версии не нужны переменные окружения и отдельная конфигурация Vercel. Развёртывание и настройка автоматической публикации требуют отдельной команды.

Для `elizabeth445/dr1`, ветка `main`, пользователь заранее разрешил автоматические коммиты и push после каждой успешно завершённой задачи на изменение сайта. Сначала выполняются аудит и подходящие проверки, затем коммит и отправка с проверкой удалённого SHA. Force push и удаление истории запрещены; при конфликтах или ошибках Git отправка останавливается с сообщением пользователю. После задачи сообщаются результат проверок, результат push и SHA. Это разрешение действует только для данного репозитория.

Общие правила аудита перед push — в `~/.codex/AGENTS.md`, местные команды — в `AGENTS.md`. Перед разрешённой отправкой проверить статус, diff, staged diff, remote и ветку; включать только задуманные изменения. `.gitignore` исключает зависимости, сборки, логи, кэши, результаты тестов и `.env*`, сохраняя безопасный `.env.example`, если он понадобится. Уже отслеживаемые секреты требуют отдельной проверки — ignore их не удаляет.
